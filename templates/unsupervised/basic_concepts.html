Conceptos Básicos / Basic Concepts

  • Unsupervised Learning: Aprendizaje sin etiquetas / Learning without labels
  • Clustering: Agrupar datos similares / Group similar data
  • K-Means: Divide datos en K grupos / Divides data into K clusters
  • Centroids: Centro de cada grupo / Center of clusters
  • Euclidean Distance: Distancia entre puntos
  • Iterations: Repetición del proceso
  • Variance: Qué tan dispersos están los datos
  • Convergence: Cuando ya no hay cambios
